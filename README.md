# FrameFlow

FrameFlow is a full-stack booking and client management platform for photographers and videographers.

The goal of the project is to provide creatives with a simple way to manage services, bookings, clients and project workflows in one place.

## Planned Features

- Client registration and login 
- Creator and client roles
- Photography and videography services
- Booking management
- Project status tracking
- Client management
- Creator dashboard
- Responsive user interface

## Planned Workflow

A typical project can move through the following stages:

- Pending
- Confirmed
- Shooting
- Editing
- Delivered
- Cancelled
