# 🎬 FrameFlow

<p align="center">
  A full-stack booking and workflow platform for photographers and videographers.
</p>

---

## 📸 About

FrameFlow is a portfolio project focused on modern full-stack web development.

The platform helps photographers and videographers manage:

- 👥 Clients
- 📅 Bookings
- 🎞️ Services
- 🗂️ Projects
- 🔄 Project progress

The goal is to create one central workspace for the entire workflow — from the first booking request to final delivery.

---

## ✨ Core Features

- 🔐 Client registration and login
- 👤 Creator and client roles
- 📷 Photography and videography services
- 📅 Booking management
- 🗂️ Project tracking
- 👥 Client management
- 📊 Creator dashboard
- 📱 Responsive user interface
